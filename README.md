
# Aerolytix
### Intelligent Breath Analytics for Early Disease Screening

## Overview
Aerolytix is an experimental breath-sensing project that explores
gas-sensor data collection and visualization for screening research.

## Planned Hardware
- ESP32
- MQ-2, MQ-3, MQ-7 and MQ-135 gas sensors
- Temperature and humidity sensor
- Display and breath-sampling chamber

## Software
- Python
- Streamlit
- Pandas
- Matplotlib

## Current Features
- Simulated sensor readings
- Sensor monitoring dashboard
- Graphical visualization
- CSV data export

## Installation
Install the required libraries:

    python -m pip install -r requirements.txt

## Run
Start the dashboard:

    python -m streamlit run app.py

## Future Improvements
- ESP32 hardware integration
- Sensor calibration
- Controlled data collection
- Evaluation of machine-learning models
- Mobile application integration

## Disclaimer
This project is a research prototype and is not a medical
diagnostic tool. Simulated data cannot establish disease
detection accuracy.
